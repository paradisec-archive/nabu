# Nabu

The PARADISEC catalogue: collections of items and their files, described with the languages they contain and are about.

## Language

### Languages

**Language**:
Anything a depositor can tag a collection or item with as its content or subject language, at any level of granularity. Owned by Nabu; it exists whether or not any source has a code for it.
_Avoid_: Languoid, language code (when the thing itself is meant)

**Variety**:
A Language that is a dialect or regional variety rather than a language in its own right. A Variety carries an AUSTLANG code or a Glottolog dialect code and usually no ISO 639-3 code.
_Avoid_: Dialect (that is the free-text field on an item, not a Language)

**Code**:
An identifier a Source assigns to a Language. A Language may have one Code per Source, or none from some Sources.
_Avoid_: ISO code (when any Source is meant)

**Source**:
An external authority that publishes Codes: ISO 639-3 (via Ethnologue and SIL), Glottolog, or AUSTLANG. There are no others.
_Avoid_: Provider, vocabulary, standard
